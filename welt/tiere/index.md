# Tiere

## Tier

* [Feldhase](feldhase.md) - Flinkes Langohr auf den Feldern und Wiesen.
* [Rothirsch](rothirsch.md) - Stolzer, großer Hirsch des Rabenforsts mit gewaltigem Geweih.
* [Sumpfkröte](sumpfkroete.md) - Eine plumpe, warzige Kröte aus den schlammigen Gewässern.
* [Sumpfotter](sumpfotter.md) - Eine heimtückische, giftige Schlange im feuchten Moor.
* [Wildschwein](wildschwein.md) - Borstiges Borstenvieh mit messerscharfen Hauern im Unterholz.
